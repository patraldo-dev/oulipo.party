# Spell-check dictionaries

Hunspell dictionaries used by the editor's pre-submit check, from the
LibreOffice dictionaries collection (https://github.com/LibreOffice/dictionaries):

- `en.aff` / `en.dic` — English (United States), from `en/en_US.*`
- `es.aff` / `es.dic` — Spanish (Spain), from `es/es_ES.*`
- `fr.aff` / `fr.dic` — French, from `fr_FR/dictionaries/fr.*`

Each language's licence text lives beside it upstream (`en/LICENSE.en_US.txt`,
`es/LGPLv3.txt` among others, `fr_FR/dictionaries/README_dict_fr.txt`). The
checker only warns before a send; it is advisory, and the pieces stay the
writer's own.
